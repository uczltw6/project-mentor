# Security policy

## Supported versions

Security fixes are provided for the latest released minor line.

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| 0.1.x | No |
| Earlier or unreleased snapshots | No guarantee |

## Report a vulnerability

Please use the repository's private
[GitHub security advisory form](https://github.com/uczltw6/project-mentor/security/advisories/new).
Do not open a public issue for a suspected vulnerability and do not include real
credentials, private repository content, or personal data in a report.

Include the affected version or commit, impact, minimal reproduction using
synthetic data, and any suggested mitigation. You can expect an initial response
within seven days. Timing for a fix or disclosure depends on severity and the
scope of the change.

The security boundary and residual risks are documented in
[`docs/threat-model.md`](docs/threat-model.md).
